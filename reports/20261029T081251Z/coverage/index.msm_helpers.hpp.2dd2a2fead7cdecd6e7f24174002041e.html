32 // How a throw gets out of the machines. Boost.MSM wraps process_event in a try/catch by default
33 // and hands a std::exception to the def's exception_caught hook, whose default asserts: abort in
34 // Debug, silent in Release with the machine continuing from the interrupted transition. Catching
35 // and continuing cannot be made safe here either: an anonymous row whose action keeps throwing is
36 // re-fired by the completion event until the stack is gone. So the contexts never let a consumer
37 // callback throw into the machine: a publisher, sender or logger that throws is parked in
