17 /// \brief Voltage plausibility monitor used by EvseManager during DC charging.
18 ///
19 /// The monitor compares voltage measurements from multiple sources (power supply, powermeter,
20 /// isolation monitor, over voltage monitor) and checks that they report similar values. If the
21 /// spread (max-min) between available sources exceeds a configured threshold for a given
22 /// duration, a fault is raised.
23 ///
24 /// Thread-safety:
25 /// - Public APIs are intended to be called from EvseManager threads and from callbacks of the
26 /// external voltage source interfaces.
27 /// - Internally, a dedicated background thread waits on a fault timer condition and synchronizes
28 /// access to timer-related state via an internal mutex and condition variable.

37 /// \brief Construct a new VoltagePlausibilityMonitor.
38 ///
39 /// \param callback Function that will be called whenever a fault is detected.

41 /// voltage sources before a fault is triggered.
42 /// \param fault_duration Duration for which the max-min spread must exceed the threshold
